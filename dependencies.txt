================================================================================
  macOS Finder File Manager — Debian / Ubuntu System Dependencies Guide
================================================================================

This document details all system packages and dependencies required to either:
  [A] RUN the compiled application on Debian / Ubuntu-based Linux distros.
  [B] BUILD the application from source (Tauri v2 + Rust + React/Vite).

Tested on:
  • Debian 12 (Bookworm) / Debian 13 (Trixie)
  • Ubuntu 22.04 LTS (Jammy) / 24.04 LTS (Noble)
  • Linux Mint, Pop!_OS, Zorin OS, and Debian derivatives.

--------------------------------------------------------------------------------
1. RUNTIME DEPENDENCIES (To run the pre-built application)
--------------------------------------------------------------------------------

To run the binary (or .deb package), install the core graphical, webview,
and system utility packages:

  sudo apt update
  sudo apt install -y \
    libwebkit2gtk-4.1-0 \
    libgtk-3-0 \
    libayatana-appindicator3-1 \
    librsvg2-2 \
    libssl3 \
    udisks2 \
    curl \
    xdg-utils \
    python3

Package Descriptions:
  • libwebkit2gtk-4.1-0     WebKitGTK engine used by Tauri to render the UI.
  • libgtk-3-0              GTK 3 desktop toolkit (windowing, clipboard, native drags).
  • libayatana-appindicator3-1 System tray / indicator support.
  • librsvg2-2              Vector graphics / SVG icon rendering.
  • libssl3                 OpenSSL cryptographic library.
  • udisks2                 Required for non-root mounting/unmounting drives in sidebar.
  • curl                    Used by the download engine for background downloads.
  • xdg-utils               Provides `xdg-open` to launch files with default apps.
  • python3                 Used by the browser extension native messaging host.

*Note for Debian 11 (Bullseye) or older distros:
  If `libwebkit2gtk-4.1-0` is not available, install `libwebkit2gtk-4.0-37`.
  If `libayatana-appindicator3-1` is not available, install `libappindicator3-1`.
  If `libssl3` is not available, install `libssl1.1`.

--------------------------------------------------------------------------------
2. OPTIONAL FILESYSTEM TOOLS (For Disk Utility Format & First Aid)
--------------------------------------------------------------------------------

The file manager includes a macOS Disk Utility-style partition manager that can
format and check USB drives, external disks, and partitions. Install these to
support all filesystem formats:

  sudo apt install -y \
    dosfstools \
    e2fsprogs \
    exfatprogs \
    ntfs-3g \
    btrfs-progs

Package Descriptions:
  • dosfstools   Provides `mkfs.vfat` & `fsck.vfat` (FAT32 formatting and repair).
  • e2fsprogs    Provides `mkfs.ext4` & `e2fsck` (Linux ext4 formatting and repair).
  • exfatprogs   Provides `mkfs.exfat` (Modern exFAT USB flash drive formatting).
  • ntfs-3g      Provides `mkfs.ntfs` (Windows NTFS read/write and formatting).
  • btrfs-progs  Provides `mkfs.btrfs` (Btrfs modern filesystem formatting).

--------------------------------------------------------------------------------
3. BUILD DEPENDENCIES (To compile the project from source)
--------------------------------------------------------------------------------

If you want to build `macos-finder` from source:

STEP 3.1: Install C/C++ compiler and development headers
--------------------------------------------------------------------------------
  sudo apt update
  sudo apt install -y \
    build-essential \
    curl \
    wget \
    file \
    pkg-config \
    libssl-dev \
    libgtk-3-dev \
    libwebkit2gtk-4.1-dev \
    libayatana-appindicator3-dev \
    librsvg2-dev \
    python3

  *(On Debian 11 Bullseye, replace `libwebkit2gtk-4.1-dev` with `libwebkit2gtk-4.0-dev`
   and `libayatana-appindicator3-dev` with `libappindicator3-dev`).

STEP 3.2: Install the Rust Toolchain (Rust >= 1.77 recommended)
--------------------------------------------------------------------------------
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
  source "$HOME/.cargo/env"

STEP 3.3: Install Node.js (v18, v20 or v22 LTS) & npm
--------------------------------------------------------------------------------
Option A: Using NodeSource repository (recommended on Debian/Ubuntu):
  curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
  sudo apt install -y nodejs

Option B: Using NVM (Node Version Manager):
  curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
  source ~/.bashrc
  nvm install 20

STEP 3.4: Install project dependencies & compile
--------------------------------------------------------------------------------
  # 1. Install frontend npm dependencies
  npm install

  # 2. Build production frontend & compile standalone release binary:
  npx tauri build --no-bundle

  The compiled standalone binary will be placed at:
    src-tauri/target/release/macos-finder

  (You can run it directly: `./src-tauri/target/release/macos-finder`)

--------------------------------------------------------------------------------
4. BROWSER EXTENSION INTEGRATION (Chrome, Brave, Edge, Chromium)
--------------------------------------------------------------------------------

To enable automatic browser download interception into the macOS Finder download manager:

  1. Make sure python3 is installed (`sudo apt install -y python3`).
  2. Run the included registration script:
       chmod +x install-native-host.sh native-messaging-host.py
       ./install-native-host.sh
  3. Load the unpacked Chrome extension from the `chrome-extension` directory in:
       chrome://extensions  (Enable Developer Mode -> "Load unpacked").
